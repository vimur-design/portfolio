# Портфолио Виктории Мурадовой

[Открыть сайт](https://vimur-design.github.io/portfolio/)

Адаптивный статический сайт по макетам Figma: главная, «Обо мне» и кейсы Time, СИБУР, Северсталь и ТЭК-Торг. Левый блок с именем и контактами закреплён при прокрутке на компьютере.

Сайт работает без сборки и сторонних JavaScript-зависимостей. Тексты находятся в соответствующих HTML-файлах, общие стили — в `styles.css`, просмотр концептов — в `site.js`. Изображения экспортированы из Figma; WebP сжаты без потери качества.

Публикация: GitHub Pages → Deploy from a branch → main → /(root). Файл `.nojekyll` отключает обработку Jekyll. Внутренние ссылки относительные и работают в `/portfolio/`.
